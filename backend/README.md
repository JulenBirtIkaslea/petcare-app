# API PetCare

Laravel con Sanctum SPA y modelos adaptados a un esquema PostgreSQL en castellano. Seguir el [README principal](../README.md) para instalar y arrancar.

**Database first, sin migraciones.** El SQL está en `../database/sql/`. La BD no se consulta hasta habilitar `PETCARE_BD_HABILITADA` en `.env`.

Consultar [el contrato implementado](../docs/API_IMPLEMENTADA.md) antes de integrar endpoints. Los mapeos de módulos futuros no implican que sus servicios estén implementados.
